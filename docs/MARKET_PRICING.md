# Цены и закупки

Реализация от 14.09.2026. Раздел админки: **«Ціни та закупівлі»**. По следующему запросу владельца код передаётся в GitHub. Публикация кода сама по себе не подтверждает запуск на сайте; рабочие цены, закупочные цены, поставщики и остатки этим механизмом не изменяются.

## Расчёт

Добавляются точные предложения Milk Diller, Rozetka и Prom, до 12 продавцов на товар. Администратор сверяет бренд, состав, вариант, вес/объём и упаковку с карточкой Evergreen. Автоматического сопоставления похожих названий нет.

Для каждого предложения отдельно отмечается возможность реальной закупки и доступность обычному покупателю для розничного сравнения. Оптовую цену нельзя считать розничной, если она недоступна этому покупателю. Для разных ценовых ступеней добавляются отдельные предложения с нужными минимумами.

- Полная стоимость единицы = цена закупки + доставка партии / единиц в партии + прочие расходы на единицу.
- Требуемый заработок = большее из фиксированной суммы и процента наценки на полную стоимость.
- Нижняя цена = `(стоимость + заработок) / (1 − комиссии / 100)`, округлённая вверх до гривны.
- Розничная стоимость единицы = цена конкурента + доставка выбранного количества / это количество.
- Верхняя цена = минимальная подтверждённая розничная стоимость минус заданный отступ, округлённая вниз до гривны.

Рекомендуется нижняя цена, если она помещается под верхней границей. Иначе нужно другое снабжение или пересмотр ассортимента. Начальные 20 грн заработка и отступ 1 грн редактируются; это не подтверждённая экономика бизнеса. Комиссии, упаковку и потери нужно внести самостоятельно.

Пустая доставка означает «неизвестно», а не ноль. Минимальное количество и сумма продавца проверяются отдельно для закупки и покупки клиента. Смешанные корзины, весовые тарифы, специальные скидки и ценовые ступени автоматически не моделируются: условия вносятся для конкретного количества. Смена количества сравнения требует перепроверки доставки. Evergreen сравнивается в сценарии самовывоза.

Рекомендация относится только к добавленным продавцам и выбранному сценарию. Для полного статуса нужны пригодные предложения всех трёх площадок; иначе сравнение частичное. Это не поиск абсолютного минимума рынка.

## Источники и актуальность

Цена по умолчанию годна 24 часа; подтверждение продавца и доставки — 7 дней. Сроки настраиваются. Неизвестное наличие, ошибка последнего чтения, устаревшие данные и неподтверждённая фасовка исключают предложение. Изменение товара/продавца снимает подтверждения; скачок цены более 30% требует перепроверки условий. Чтение цены не продлевает срок ручной проверки доставки.

«Прочитати ціну» читает публичный HTML с одним однозначным Product/Offer в JSON-LD и валютой UAH. Сводные минимумы, несколько товаров/продавцов, CAPTCHA и HTTP 403 не обходятся. При отказе старая цена видна, но исключена из расчёта до проверки. Есть ручной ввод. Разрешены HTTPS-ссылки на `milkdiller.ua`, `rozetka.com.ua`, `prom.ua` (и www); сторонние домены магазинов Prom не поддержаны.

Проверка доступа 14.09.2026:

| Источник | Одна контрольная карточка |
| --- | --- |
| [Milk Diller](https://milkdiller.ua/moloko-ta-vershki/pitne-moloko/koktejl-molochnij-vershkovo-vanilnij-2-5-212g) | Прочитаны название, цена, продавец и наличие |
| [Rozetka](https://rozetka.com.ua/ua/lavazza_8000070020566/p9770268/) | HTTP 403; ручной ввод либо согласованный источник данных |
| [Prom](https://prom.ua/p3144012294-kofe-zernah-lavazza.html) | Сводное предложение; цена не принята автоматически |

Проверялась доступность чтения, а не соответствие этих товаров между собой. Одна страница не доказывает доступность всей площадки.

[API Prom](https://public-api.docs.prom.ua/) предназначен для кабинета продавца; [инструменты Rozetka](https://sellerhelp.rozetka.com.ua/p841-items-setup-methods-overview.html) — для размещения и управления собственными товарами. Это не готовые общерыночные потоки цен конкурентов. Для устойчивого массового мониторинга нужен согласованный прайс/фид продавцов или другой разрешённый источник. [Доставка Rozetka](https://help.rozetka.com.ua/p/54-yak-dostavlyayutsya-zamovlennya-vid-prodavciv-marketplejsu/) зависит от способа получения, города, веса и габаритов; бывает бесплатной, поэтому фиксированную доставку всем конкурентам приписывать нельзя.

## Хранение и запуск

Профили сохраняются отдельно в `market_price_profiles`, с проверкой revision при одновременной работе с устройств и последними 60 изменениями цены/наличия. Все маршруты `/api/admin/pricing` требуют сессию администратора. Расчёт не меняет `Product.price`, `costPrice`, `supplierId`, `active`, `stockStatus` или правила заказов. Выбранная цена применяется через существующий редактор после проверки фактической закупки.

Локальный просмотр: `npm run preview:design`, `/preview/admin`, раздел «Ціни та закупівлі». В деморежиме профили живут только в памяти вкладки до перезагрузки страницы. Записи в реальную базу и сетевое чтение предложений выключены.

Для полноценного сохранения позднее нужны PostgreSQL, миграция `20260914120000_market_price_profiles` и генерация Prisma-клиента. В этой задаче схема проверена и клиент сгенерирован; миграция ни к одной базе не применялась. Сохранение проверено с подменой БД, а не на рабочем PostgreSQL.

`npm run prices:refresh` — отдельный процесс обновления исследовательских предложений. Требует `USE_POSTGRES=true` и корректную БД. Только профили с включённым мониторингом: до 20 за запуск (`PRICE_MONITOR_LIMIT`, максимум 100), до 40 последовательных запросов. Ошибки/конфликты дают ненулевой код; цены магазина не меняются. Планировщик не создавался, процесс не запускался. Перед будущим включением нужны проверка источников на сервере и выбор частоты с учётом ограничений площадок. Лимит не обеспечивает обновление неограниченного каталога за один запуск.

## Проверки

`npm run test:pricing`: формулы, комиссии, доставка, минимумы, свежесть, неоднозначные предложения, сетевые ограничения, конфликты сохранения и запрет анонимного доступа. `npm run test:storefront`: покупательские сценарии. Демоформа проверена на 320/390/768/1280: ввод, сохранение/загрузка, отказ убыточной рекомендации, отказ чтения, клавиатурный фокус и reduced motion. Настоящие заказы и синхронизация поставщика не запускались.
