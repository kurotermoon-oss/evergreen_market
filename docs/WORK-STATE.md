# Текущее состояние — 20.09.2026

## Готово
- Добавлен внутренний Telegram Mini App закупок `/telegram/supply`: общий аккаунт без ответственных; склад/витрина, ежедневные и недельные проверки, количество и примечание, закупки по поставщикам, ожидаемые поставки, переносы/получение и история.
- Графики учитывают киевское время, дни заказа и доставки, сроки и исключения. Начальные данные — неподтверждённые черновики; неизвестные дедлайны пустые.
- Отдельные Telegram-авторизация/API и три новые PostgreSQL-таблицы. Ревизии защищают изменения двух устройств. Worker хранит этапы/повторы уведомлений, координируется advisory lock; работает только после настройки и включения.
- Реальные заказы поставщикам не отправляются. Таблицы магазина и Milk Diller cron не изменены.
- Документация подключения: docs/SUPPLY_BOT.md; безопасный деморежим `/preview/supply` через `npm run preview:design`.

## Проверки
- Финальная production-сборка, prisma validate, синтаксис backend — успешно.
- test:supply 21/21; test:telegram-admin 12/12; test:storefront 25/25.
- UI 320/390/768/1280 px без горизонтального переполнения. Проверены количество → закупка → дата → получение → новая проверка; отложенная закупка; завершение витрины; подтверждение/валидация графика; недельная позиция; Tab/Escape/возврат фокуса. Ошибок консоли нет; движения нет, reduced-motion правило присутствует.
- Демо отсутствует в production bundle. Реальные БД/Telegram не использовались в QA.

## Далее / ограничения
- Подготовлено к разрешённой публикации main → Railway; перед коммитом origin/main повторно проверен, расхождений нет. Итог публикации проверяется отдельно в ответе задачи.
- Реальный запуск требует токена выбранного бота, allowlist/ID общего аккаунта, Start и переменных Railway; затем supply:connect и подтверждение графиков. Токены не отправлять в чат/GitHub.
- Отправка Telegram и блокировки реального PostgreSQL до подключения не проверены. Worker-тесты используют тестовое хранилище. После подключения выполнить совместную проверку на двух устройствах и контрольное уведомление.
