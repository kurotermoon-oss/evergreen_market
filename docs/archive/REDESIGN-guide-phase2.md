## Раздел «Як це працює»

Новая страница подключена к обычному маршруту `/how-it-works` в локальном проекте и включается в production-сборку. Ссылка в шапке ведёт на неё. Старый адрес локального просмотра `/preview/how-it-works` остаётся DEV-only псевдонимом того же компонента, без второй версии страницы.

- Один первый экран: объяснение закупки для кав’ярни и небольшой наценки, основная кнопка каталога, гостевое оформление и самовывоз.
- Локальная SVG-иллюстрация пакета с продуктами использует существующий логотип. Дополнительных изображений из сети, шрифтов или зависимостей нет.
- Три шага: выбрать товары, оформить выбранную группу, забрать после подтверждения. Ссылка на корзину находится во втором шаге.
- Сравнение «Є в наявності» / «Під замовлення»: минимальная сумма и готовность к выдаче видны сразу.
- Адрес, часы самовывоза, неактивная доставка и переход к контактам.
- Три раскрывающихся ответа: выгода, группы корзины, сроки. Открывается один ответ за раз; поддерживается клавиатура.
- Убраны плавающие корзина и обратная связь только на этой информационной странице. Ссылки на корзину и Telegram находятся в содержимом; мобильная навигация сохранена. На других экранах плавающие действия продолжают работать.
- Лёгкие анимации при появлении; содержимое всегда доступно и при отключённой анимации. `prefers-reduced-motion` отключает эффекты.

Цены, проценты экономии и сроки выдачи не выдумываются. Телефон **или** Telegram; каждый поставщик имеет свою группу и свой минимум; товары из другой группы не засчитываются. Серверная логика оформления не менялась.

## Локальный просмотр

- `npm run preview:refresh` или `node scripts/refresh-preview-data.mjs`: обновить только публичные снимки товаров и категорий.
- `npm run preview:design` или `node scripts/preview-design.mjs`: запустить просмотр на `http://127.0.0.1:5180/`.
- Готовый раздел: `http://127.0.0.1:5180/how-it-works`.
- `npm run build` или `node scripts/build.mjs`: production-сборка.

Снимки находятся в `.preview/`, исключены из Git. Режим просмотра явно включается переменными `EG_READONLY_PREVIEW` и `VITE_READONLY_PREVIEW`; API-изменения отклоняются, приватные данные не выдаются. Обычный `npm run dev` сохраняет работу с существующим backend.

Снимок каталога не гарантирует актуальную цену или наличие. Реальные вход в аккаунт и отправка заказа в этом режиме не проверяются.
