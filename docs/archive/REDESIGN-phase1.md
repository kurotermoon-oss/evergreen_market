## Предпросмотр

1. `npm run preview:refresh` — обновить снимок публичных товаров и категорий. Требует доступ к интернету; приватные данные не запрашиваются.
2. `npm run preview:design` — открыть `http://127.0.0.1:5180/`.
3. Новая инструкция: `http://127.0.0.1:5180/preview/how-it-works`.

В `.preview/` хранятся только локальные снимки, исключённые из Git. API-запросы изменений возвращают 403; приватные административные GET закрыты. Вход в реальные аккаунты и создание заказа здесь не проверяются. Каталог, поиск, карточки, локальная корзина и вёрстка работают с публичными товарами. Снимок не является гарантией текущей цены или наличия.

Для полноценного приложения остаётся `npm run dev`: он использует существующий backend и его обычную конфигурацию. Режим предпросмотра включается только явно и не действует в производственном сервере.
