# Astra 6 — экономная работа над Evergreen

Источник: https://developers.openai.com/api/docs/guides/latest-model, прочитан 07.09.2026.

`AGENTS.md` управляет поведением агента, но не биллингом и параметрами запуска. Экономия здесь достигается точным контекстом, короткими ответами и проверками по масштабу задачи. Процент экономии без замеров неизвестен.

Для владельца: выбирайте low для текста и CSS, medium для новой функциональности, high для сложных ошибок. Сравнивайте не только длину ответа, но и время до готового результата и количество переделок. Max/ultra не нужны как постоянный режим для лендинга. Текущие настройки приложения этой работой не менялись.

Если позднее появится API-приложение: идентификатор — `gpt-6-astra`; для инструментов нужен Responses API. `none` не поддерживается; `temperature`, `top_p`, `top_logprobs` не передавайте. Поддерживаются async-инструменты и уточнения во время выполнения. Смену reasoning с сохранением префикса кеша можно делать через `configuration_update` с учётом ограничений совместимости. При миграции старого кеширования документация указывает `prompt_cache_options.ttl: "30m"`; учитывать нужно также оплату записи кеша. Это справка, а не включённая настройка проекта.

Практичный шаблон запроса:

> Измени [конкретный блок]. Покупатель должен [результат]. Сохрани [ограничения]. Готово, когда [проверяемые критерии]. Обычные решения принимай самостоятельно. В конце коротко перечисли изменения и проверки.

Пример:

> На лендинге сделай кнопку каталога заметнее на телефоне. Сохрани зелёную палитру и текущие ссылки. Кнопка не должна перекрывать текст, а страница должна работать без JavaScript. Проверь затронутые стили и собери пакет.
