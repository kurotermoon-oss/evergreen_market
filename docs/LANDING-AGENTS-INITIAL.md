# Evergreen: рабочие правила

## Контекст и результат
- Evergreen coffee — кофейня и маркет в Киеве, Білицька, 20. Закупаем для кофейни оптом и предлагаем соседям товары с небольшой наценкой.
- Общение с владельцем — по-русски; текст для покупателей — по-украински.
- Лендинг: `landing/index.html`, `landing/styles.css`, `landing/script.js`. Без сборщика и сторонних JS-зависимостей. Сборка пакета: `node scripts/build.mjs`. Предпросмотр: `node scripts/serve.mjs`.
- Сохраняй зелёную палитру, реальные контакты, доступность, адаптивность и быстрый переход в действующий каталог. Не выдумывай цены, скидки, отзывы, сроки и наличие.
- Самовывоз активен. Доставка пока не активна. Для товаров под заказ минимум считается по поставщикам; для наличных товаров такого минимума нет. Перепроверь условия перед их изменением.
- Приоритет размещения — существующий сайт. Не подключай платные сервисы без запроса владельца.

## Экономное выполнение
- Начинай с нужных файлов и точечного поиска `rg`. Не перечитывай весь проект, минифицированные файлы `reference/`, историю и документацию без причины.
- Формулируй критерий готовности и выполняй задачу до результата. Обычные обратимые решения принимай самостоятельно; задавай вопрос, только когда ответ существенно меняет результат.
- Сохраняй сделанную работу при новых указаниях. Не переписывай готовые части без необходимости.
- Объединяй независимые чтения и проверки. Не запускай агентов без явного запроса. Предпочитай небольшие изменения и существующие средства новым зависимостям.
- Проверяй затронутые сценарии. После успешной проверки не повторяй её без изменений или новых оснований. Не создавай тесты, просто повторяющие разметку.
- Завершай кратко: результат, проверка, реальные ограничения. Не печатай большие файлы и логи в чат.

## Astra 6: границы настроек
Эти правила сокращают лишнюю работу, но не переключают модель, тариф или уровень reasoning. Настройки меняются в интерфейсе Codex либо приложении, вызывающем API. Не утверждай, что изменил их через этот файл.

Для простых правок рекомендуй `low`; для составных изменений — `medium`; `high` — для трудной диагностики. Это рабочая эвристика, а не гарантия стоимости. Не снижай качество ради лимита; сообщай о реальном препятствии. Модель не заменяй без запроса.

API-справку и шаблон постановки задач читай в `MODEL-NOTES.md` только при работе с моделью. Для задачи лендинга OpenAI API не нужен.
